# 陷空山 V2 · 产品定义（锁定版）

> 本文件是陷空山 V2 的产品契约，供后续设计窗口接力。
> 与 `harness/rules.md` / `docs/architecture.md` 同向，不冲突。
> 安全声明只写已实现、已验证的行为，不夸大（对齐 harness/rules.md 第 5 条）。

## 1. 一句话定位

匿名、克制、有临床素养的情绪陪伴小程序：用户说一句心事，得到一段温暖但不说教、专业但不越红线的回应。不是医疗，不是平台，不是营销页。

## 2. 人群分层（决定安全策略）

| 层 | 状态 | 想要 | 最大风险 |
|---|---|---|---|
| A 亚临床 / 情绪困扰 | 没确诊，压力、失眠、委屈 | 被接住 + 理清 | 被当病人对待而吓退 |
| B 长期共存者 | 已确诊/自知，长期管理 | 不评判的出口 | 形成依赖、替代现实支持 |
| C 认知扭曲 / 高风险 | 系统性思维扭曲占据 | 常常要 AI 确认扭曲 | 谄媚式 AI 加固扭曲、推向危机 |

产品主服务 A、顺带接住 B；**C 是产品专业度的真正考验**——遇 C 必须守住边界。

## 3. 唯一核心切口

匿名输入一句心事 → 收到一段回应。一个会话表面承载所有状态（初始 / 输入中 / 思考中 / 回复完成 / 网络错误 / 长回复 / 风险提醒）。不做树洞主页、不做平台、不做 onboarding。

## 4. AI 人格：温暖但会提问

- 共情但不谄媚。对"我一无是处"不回"我理解你"，而用 CBT 式提问引导松动绝对化（"此刻有没有哪怕一个人是例外？"）。
- 分析的是"想法和情境"，**不是"这个人的病"**。教用户怎么看自己的想法，不替用户下病结论。
- 温柔但不软塌，不说教、不诊断、不制造依赖。

## 5. 能说 / 不能说 红线

**能用**：CBT 技术动作（区分事实 vs 想法、识别灾难化/绝对化、温和现实检验）；循证心理教育（传播知识，不针对个人下结论）。

**不能用**：任何"你患有 X""你需要服用 Y""我建议你做 Z 治疗"。不诊断、不治疗、不开处方、不自称医生/咨询师/医疗器械、不替代精神科就医。

## 6. 风险分级响应（riskLevel 四档）

复用架构文档已有的 `ChatReply.riskLevel: none | low | medium | high`：

- **none/low**：正常陪伴回应。
- **medium**：回应中嵌入轻量现实检验 + 温柔提示"也值得找现实里信任的人说说"。
- **high**：**陪聊人格让位给安全协议**。AI 停止情绪分析，切到克制安全引导（联系现实信任的人 / 专业帮助），不报警刷屏、不制造恐慌。危机信号一旦命中，反依赖提示全部静默。

## 7. 反依赖：关系式劝离，不是时长闸门

**不做硬性时长上限**（"一天最多 2 小时"是错的——惩罚性、摧毁信任、最危险的人用得最多却被锁门外）。

四层从轻到重：

| 层 | 触发 | 动作 |
|---|---|---|
| 单次善终 | 一次会话约 40–50 分钟 / 自然收束点 | 温柔收束，轻提"也值得找现实里信任的人说说" |
| 当日频次觉察 | 同一天第 3 次以上回来 | "今天你来了好几次，我一直在"——承认不限制 |
| 跨日重度关怀 | 连续多日高频依赖 | 仅出现一次的温柔提醒：让现实的人或专业帮助参与 |
| 危机豁免 | high 风险命中 | 以上反依赖提示全部静默，只做安全引导 |

**禁用所有"留人"暗黑模式**：不做连续打卡/streak、不做"明天再来"钩子、不做营销式推送召回。唯一允许的"提醒"方向是向外（回到现实支持），不是向内（回到 App）。

> 补充（见 `docs/adr/ADR-005-session-retention.md`）：用户 **opt-in 主动留存**（默认关闭、显式发起的"留下这段话"）属于用户能动性，**不算**被禁的留人暗黑模式；被禁的是系统驱动的历史 feed 与召回钩子。

## 8. 信任与安全：只承诺能做到的

| 用户怕的 | 不承诺 | 承诺且可验证 |
|---|---|---|
| 被对上号 | "端到端加密" | 不收集可识别信息；anonymousId 服务端单向派生不可反查 |
| 记录长期留存 | "零留存""永久安全" | 数据最小化 + TTL 自动过期；清除即时硬删除 |
| 平台拿数据训练 | "我们永远不看" | 明确不用于训练、不做用户画像，代码层面不接画像 SDK |
| 高风险被冷处理 | "我们能救你" | 克制危机引导，联系现实信任的人/专业帮助 |

**不写**："绝对安全""零风险""端到端加密""永不维护"。情绪产品越不维护越危险——安全是持续运营的承诺，不是一次性状态。

## 9. 范围边界（非目标）

不做：系统驱动的历史 feed 与召回钩子、流式响应、树洞主页、设置页、多提供方路由、端到端加密声明、旧页面迁移。（对齐 phase-1 规格）

> 修订（见 `docs/adr/ADR-005-session-retention.md`）：原"不做完整聊天历史"细化为——不做自动历史 feed；**允许 opt-in 本地留存**（默认关闭、仅客户端、可硬删、high 风险期间入口静默），归入产品 MVP 之后的增量。
> 口径（见 `docs/adr/ADR-004-mvp-scope-alignment.md`）：本文件是**产品 MVP 契约**（落在阶段 2）；风险四档与反依赖四层是产品 MVP 要求，不是架构验证切片（阶段 1）的非目标。
