# ADR-001：V2 全新重写

## 状态

已接受，等待项目创建。

## 背景

当前小程序是一个可运行的原型，但不是可规模化演进的产品基础。

已知问题包括：

1. 安全声明与实现不匹配。
2. 工程验证不完整。
3. 源代码和生成代码模式混杂。
4. 偏补丁式的运行时修复。
5. 文档与实现漂移。

## 决策

陷空山 V2 将作为全新工程构建。

旧项目保留为业务参考和应急回退方案。阶段 1 验证通过后，新功能开发应以 V2 为目标。

## 影响

正向影响：

1. 从第一天开始建立清晰架构边界。
2. 更适合 React 取向的开发方式。
3. 更便于 AI 执行器驱动的实现。
4. 降低继承技术债的风险。

负向影响：

1. 初始功能对齐会延后。
2. 部分现有实现细节必须重新验证。
3. 迁移需要明确的范围控制。

## 验证

阶段 1 必须先证明新架构能够跑通一个最小纵向切片，然后才能扩展范围。
