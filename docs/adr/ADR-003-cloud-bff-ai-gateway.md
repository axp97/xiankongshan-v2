# ADR-003：微信云开发 BFF 与 AI 网关

## 状态

已接受，等待项目创建。

## 背景

项目首先面向微信小程序。微信云开发提供原生身份能力、云函数、数据库和运维简化能力。

AI 提供方集成不得泄漏到 UI 或领域代码中。

## 决策

V2 使用微信云开发作为 BFF 层。

AI 调用经过 `aiGateway` 云函数。提供方特定协议隔离在网关之后。

## 边界

允许：

```text
UI -> aiGatewayClient -> aiGateway -> 提供方适配器
```

禁止：

```text
UI -> DeepSeek/OpenAI/Anthropic 原生协议
```

## 影响

正向影响：

1. 客户端没有 API 密钥。
2. 前端协议稳定。
3. 更容易替换提供方。
4. 形成更好的安全和可观测性边界。

负向影响：

1. 需要监控云函数延迟。
2. 流式支持可能需要单独验证。
3. 提供方特定高级能力需要显式映射。

## 验证

阶段 1 必须证明 UI 只接收归一化的应用层 AI 响应。
