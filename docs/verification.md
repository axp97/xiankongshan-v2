# 陷空山 V2 验证

## 1. 目的

本文档定义每个阶段如何完成验证。

任务并不是因为代码存在就算完成。只有验证标准通过，任务才算完成。

## 2. 必需验证层级

| 层级     | 含义                                   |
| -------- | -------------------------------------- |
| 类型检查 | TypeScript 严格模式通过                |
| 静态检查 | 代码风格和静态检查通过                 |
| 单元测试 | 领域层行为已有测试覆盖                 |
| 冒烟检查 | 最小用户路径可通过手工或自动化方式运行 |
| 架构评审 | 实现遵守已文档化的架构边界             |

## 3. 阶段 1 验收标准

只有以下全部成立，阶段 1 才算通过：

1. Taro 小程序可以成功启动。
2. 首页渲染无运行时错误。
3. 可以从 UI 发送一条测试消息。
4. 页面不直接调用 `wx.cloud.callFunction`。
5. 云函数调用经过基础设施客户端。
6. AI 响应在到达 UI 前已完成归一化。
7. UI 不依赖 AI 提供方原生字段。
8. TypeScript 严格模式通过。
9. 至少一个领域层单元测试通过。
10. 错误使用稳定的应用错误码。
11. 不声明未实现的安全能力。
12. 不意外实现阶段 1 非目标。

## 4. 架构评审清单

接受变更前，需要验证：

1. 页面层没有直接使用云端协议。
2. UI 中没有提供方字段。
3. 领域边界之间没有 `any`。
4. 业务规则没有隐藏在页面组件里。
5. 没有缺少架构理由的新依赖。
6. 没有重复事实源。
7. 文档没有与实现相矛盾。

## 5. 最小命令集

```bash
npm run verify   # typecheck + lint + test + build:weapp
```
