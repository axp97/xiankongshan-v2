# 隐私保护指引（草案，待审定后填入小程序后台）

> 用途：微信小程序后台「用户隐私保护指引」申报 + 应用内隐私说明的事实源。
> 原则（product-definition.md §8 / harness/rules.md §5）：只写已实现、已验证的行为，不夸大；
> **不写**「端到端加密」「零风险」「绝对安全」等未实现承诺。

## 一、我们处理哪些信息

1. **你输入的对话内容**
   - 用途：仅用于生成当次回应。文本会经过内容安全检测，并发送给 AI 服务提供方（DeepSeek）处理以生成回复。
   - 我们不在服务端存储你的对话内容，不用于模型训练，不建立用户画像。
2. **微信 openid**
   - 用途：仅用于单向派生一个匿名标识（SHA-256 哈希，不可反查回你的身份），以便基础服务运行。
   - 我们不要求注册、不收集昵称/头像/手机号。
3. **设备本地数据**
   - 使用节律的少量本地记录（用于温和的使用提醒），仅保存在你的设备上，不上传服务器；清除小程序数据即删除。

## 二、我们不收集什么

不收集手机号、位置、通讯录、相册、设备标识以外的任何信息；无广告、无第三方统计追踪。

## 三、第三方处理说明

生成回应时，你输入的文本（不附带任何身份信息）会被发送至 AI 服务提供方 **DeepSeek** 的接口进行处理。接口密钥保存在服务器端，不在小程序客户端。

## 四、你的控制权

- 匿名使用：全程无需注册或绑定身份。
- 随时清除：会话页「隐私与边界 → 清除本次内容」可从当前设备移除本次对话。

## 五、边界声明

本小程序提供的是情绪支持内容，**不是医疗诊断、心理治疗或危机干预服务**，不能替代医生、咨询师或专业机构。若你正处于紧急危险中，请立即联系现实中可信任的人或专业帮助。

## 小程序后台申报对照（勾选项）

| 后台信息类型 | 是否处理 | 说明 |
| --- | --- | --- |
| 用户输入的文字内容 | 是 | 对话文本，用于生成回应，不存储 |
| OpenID | 是 | 单向派生匿名标识 |
